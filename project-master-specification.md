# Master Frontend & System Implementation Specification — Interview Transcriber Studio

This document serves as the comprehensive master blueprint and technical specification for the **Interview Transcriber & AI Summarization Platform**. It details every UI section, user experience (UX) flow, component structure, database schema, AI diarization pipeline, the official 12-question interview bank, and Excel export formats.

---

## 1. Executive UX Flow & Application Navigation

```
  /login  ────── sign in ──────▶  /candidates (Dashboard)  ────── select ──────▶  /session/:id
                             │                                                       │
                             ├────── Export Master Excel (All Tabs) ────────────────┤
                             ├────── Reset Database (Password Protected) ───────────┤
                             └────── Add Candidate / Manage Questions ──────────────┘
```

1. **Login Page (`/login`)**:
   * Shared admin password authentication (`admin123` or `admin`).
   * Animated audio waveform equalizer graphic (`SIGNAL / ADMIN ACCESS`).
   * Inline validation error handling (no browser alert popups).

2. **Candidates Roster Dashboard (`/candidates`)**:
   * Main landing hub displaying all candidate profiles as interactive cards.
   * Status indicators (`Not Started` amber outline, `In Progress` amber filled, `Completed` teal filled).
   * **Master Excel Export Button**: Generates a multi-tab Excel workbook containing an overview directory AND a dedicated individual tab for each candidate.
   * **Password-Protected Database Reset Modal**: Red "Reset Database" topbar button requiring admin password confirmation to clear old test recordings and re-seed clean candidates and questions.
   * Inline **"+ Add Candidate"** form for expanding the candidate roster.

3. **Session & Interview View (`/session/:id`)**:
   * **Header Card**: Candidate profile details, role, department, and live interview progress bar (`x of 12 questions completed`).
   * **Continuous Full-Interview Audio Recorder**: Prominent `"🎙️ Start Full Interview Rec"` button capturing high-quality 128kbps Opus audio with noise suppression.
   * **Question-by-Question Question Bank**: Displays all 12 official interview questions categorized by section.
   * **Take Cycling State**: `Idle → Recording → Uploading → Transcribing → Saved`.
   * **Executive AI Summaries**: Clean 1-2 sentence candidate answer summary generated by AI with interviewer questions stripped out.
   * **Pinned Custom Question Input**: Bottom input bar to insert spontaneous questions on-the-fly.

4. **Question Bank Manager View (`/questions`)**:
   * View and manage pre-decided questions grouped by category.
   * Add custom domain-specific questions to the shared question bank.

5. **Settings & AI API Configuration View (`/settings`)**:
   * Configure Groq API Key (`gsk_...`), Google Gemini API Key (`AQ...` / `AIzaSy...`), Cloudinary Cloud Name (`neugchyg`), and LLM models.

## 2. Official 12-Question Interview Bank

The platform strictly enforces the following official 12-question interview structure across all candidates:

| Q# | Category | Question Prompt | Assessment & Evaluation Objective |
|---|---|---|---|
| **Q1** | Background & Overview | *Name, introduce yourself.* | Career background, self-presentation, and communication clarity. |
| **Q2** | Project & Strategy | *What is your problem statement.* | Problem identification, project scope clarity, and core motivation. |
| **Q3** | Project & Strategy | *What is your approach/implementation plan to your project?* | System architecture, technical roadmap, model selection (e.g. UNet/ResNet GANs). |
| **Q4** | Domain Technical | *Basic questions on your domain.* | Core technical fundamentals, domain competence, and subject matter depth. |
| **Q5** | Data Structures & Ideation | *Ask a DSA question and basically just know their ideation capabilities.* | Algorithmic thinking, data structure selection, and creative problem-solving under pressure. |
| **Q6** | Training & Development | *What did you understand about training and development?* | Growth mindset, learning agility, and receptivity to technical feedback. |
| **Q7** | Career Vision & Tech Role | *What do you think that YOU would do in tech?* | Long-term career ambitions, engineering passion, and technology vision. |
| **Q8** | AAC Focus Area | *What area in AAC that you are most interested in?* | Alignment with AAC focus domains, research interests, and specialized skills. |
| **Q9** | Domain Spontaneity | *Spontaneous question based on candidate domain & background.* | On-the-spot thinking, adaptability, and deep domain spontaneity. |
| **Q10** | Logistics & Availability | *Are you able to stay after hours when required for project delivery?* | Commitment, availability, time management, and project delivery flexibility. |
| **Q11** | Mentorship & Leadership | *Are you interested in becoming a mentor to junior team members?* | Leadership potential, eagerness to share knowledge, and team impact. |
| **Q12** | Behavioral & Soft Skills | *Behavioural question: Describe a challenging situation and how you navigated it.* | Emotional intelligence, resilience, conflict resolution, and teamwork. |

## 5. Master Multi-Tab Excel Export Format

When clicking **"Export All Candidates Excel"**, the server generates a single master `.xlsx` workbook formatted as follows:

### **Tab 1: `All Candidates Directory`**
Overview table containing all candidate profiles:
* `ID`: Candidate sequence number
* `Candidate Name`: Full name
* `Role / Position`: Target role
* `Department`: Department
* `Email`: Email address
* `Status`: `Not Started` / `In Progress` / `Completed`
* `Date Added`: YYYY-MM-DD
* `Total Sessions`: Count
* `Full Interview Audio Link`: Direct clickable Cloudinary audio URL
* `Notes`: Recruiter notes

### **Tabs 2 to N: Dedicated Sheet per Candidate (e.g. `Alex Morgan`, `Samantha Vance`)**
Each candidate gets their own individual sheet tab inside the workbook:
* **Header Section**: Candidate Metadata (Full Name, Role, Department, Email, Full Session Audio Link).
* **12-Question Table (Questions 1 to 12 in Order)**:
  * `Q#`: 1 through 12
  * `Section Category`: Question Category
  * `Question Prompt`: Official question text
  * `Executive AI Summary`: Crisp 1-2 sentence summary of ONLY candidate answer
  * `Key Insights & Strengths`: Key candidate takeaways
  * `Duration (s)`: Recording duration in seconds
  * `Audio Recording Link`: Clickable Cloudinary link for that question/session
  * `Clean Candidate Answer`: Spoken candidate answer text with interviewer questions stripped out
